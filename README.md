THORNPASS — a turn-based tactics game: four wardens escort a caravan through five mountain passes, and the terrain itself is the weapon. Thorn ambushes, ice slides, high ground, mud and wind combos.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser.

## How to play

Click a warden, then a lit tile to move; click an enemy in range to attack.
Keys 1–4 use abilities, Space ends the turn, Esc pauses, M mutes.
High ground adds +2 damage, thorns wound, ice slides, mud holds, wind pushes.
Win a pass by getting a wagon to the far gate; lose it if every wagon is
destroyed or every warden falls. Cross all five passes to win the campaign.
